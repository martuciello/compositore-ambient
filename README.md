# Compositore Ambient

© 2026 Mauro. Tutti i diritti riservati: vedi `LICENSE.txt`.

Compositore di brani per pianoforte ambient: progressioni armoniche, figure di mano sinistra e celle melodiche, con piano roll, libreria personale ed esportazione audio e MIDI. Funziona interamente nel browser; brani, libreria e impostazioni restano sul dispositivo di chi lo usa.

Il file `index.html` è compresso: il codice leggibile resta nell'archivio dell'autore.

## Pubblicazione

La pagina è pubblicata con **GitHub Pages** dal branch `main`, cartella principale:
`https://martuciello.github.io/compositore-ambient./`

Ogni nuovo caricamento su `main` si pubblica da solo in uno o due minuti.

## Installarlo sul telefono

Apri l'indirizzo con Chrome (Android) o Safari (iPhone):
- **Android**: menu ⋮ → **Aggiungi a schermata Home**;
- **iPhone**: Condividi → **Aggiungi alla schermata Home**.

Dopo la prima apertura funziona anche senza rete.

## Provarlo sul PC

Dalla cartella esegui `python3 -m http.server 8000` e apri `http://localhost:8000` (aprire `index.html` con un doppio clic non carica i campioni).

## Dati

Il lavoro si salva nel browser del dispositivo. Per spostarlo: **I miei brani → Copia di sicurezza in un file**, poi **Ripristina da file** sull'altro dispositivo. Il file è compatibile anche con la versione su claude.ai.
